## 1. 金融 AI agent 的安全边界开始被写成可验证的身份、授权和交易协议

**核心判断：** MAS 的 Know Your Agent 方案把 agent 安全从一般权限提醒推进到金融机构可执行的验证流程：交易前确认 agent 代表谁、具有什么权限、受何种限额约束以及是否可信。

- Event ID：`mas-know-your-agent-finance-protocol`
- 事实：MAS 的[正式演讲](https://www.mas.gov.sg/news/speeches/2026/keynote-address-by-md-at-the-singapore-fintech-festival-2026)说明协议字段、银行验证和 sandbox；[CNA](https://www.channelnewsasia.com/watch/mas-warns-against-giving-ai-agents-login-details-financial-accounts-6566321)报道其账户凭证警告。
- 变化：由风险警告和 Muse 事故，转向交易基础设施和试验场。
- 机制与受影响者：共同协议传递身份、代表关系、授权和可靠性，影响银行、支付机构、客户、企业财资与 agent 提供商。
- 问题信号：账户凭证不能证明 agent 的授权边界与错误交易责任。
- 反证：尚非生产系统或强制标准；接入复杂；过严限制可能削弱价值。
- 不确定性：标准、参与方、跨境互认和责任分配未知。
- 高置信度，100/100。

- Event ID：`indonesia-reviews-us-ai-chip-curbs`

- 中置信度，93/100。
